Sprint 1:
Throughout the project I have learned quite a bit about different Godot systems. I did some work with polygon2Ds, navigation polygons, tilemap modifying with code, and quite a few other things. It was very difficult to make it so that we couldn't place a tower that would block the path of the troops. I was surprised as to how easy several things I was overcomplicating were after I figured it out. Godot made several things easy that I didn't know about.

Sprint 2:
In this sprint I mostly worked on improving old systems. I also implemented some floating features into the HUD. The two-player system is coming along nicely, and we have a base system that is very easy to grow on. With a little more work I will add in next sprint it will be very easy to add new stuff. But this sprint was mostly cleaning up. I made some code more reusable and fixed some other things. I plan to add keyboard controls over spring break which could be cool.

Sprint 3:
In this sprint I did some cool stuff with territory. I made it so that when we delete a tower, the corresponding territory gets updated. It evens refills any enemy territory that should have taken that space over. You can't take over territory of an enemy anymore. This gets rid of an unfair strat. I also made it so towers could be sold and they work with everything. I put in keybaord controls so we don't need to grab controllers to play. I also did some less notable things that I forgot about. I was surprised at how easy it was to put in keyboard controls. I just had to put in a cursor node with an area2D to interact with the HUD. I think our biggest issue in this sprint was dealing with merge conflicts. We lost quite a bit of time to fixing those issues. I think it all turned out well though. I learned how to resolve them better this time.
